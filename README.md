# Palworld パートナースキル データベース

Palworld **v1.0** のパートナースキル一覧データベースと、特徴（タグ）ごとに絞り込めるフィルタ UI を、
**ビルド不要の静的アプリ**として提供します。GitHub Pages でそのままホストできます。

> ⚠️ 対象バージョンは **v1.0** です。β版から効果が変更されているスキルが多数あるため、
> β版時代の情報（stack 可・効果値など）とは区別して扱います。

## 構成

```
docs/                 # GitHub Pages の公開ルート（ビルド不要でそのまま配信）
├─ index.html         # UI 本体
├─ css/               # スタイル
├─ js/                # フィルタ/描画ロジック（バニラ JS, ES Modules）
└─ data/
   ├─ schema.md       # データスキーマ定義
   ├─ tags.json       # タグ（特徴）マスタ
   └─ skills.json     # パートナースキル本体データ
design/               # 設計ドキュメント（調査・スキーマ設計・UI 設計）
```

## ローカルでの確認

ビルド不要です。`docs/` を静的サーバで配信するだけで動きます。

```bash
cd docs
python3 -m http.server 8000
# → http://localhost:8000
```

（`fetch` で JSON を読むため、`file://` 直開きではなく HTTP サーバ経由で開いてください。）

## GitHub Pages 公開手順（人間側の操作）

このリポジトリは「ブランチの `/docs` フォルダから配信」する方式です。

1. GitHub のリポジトリ **Settings → Pages** を開く
2. **Build and deployment → Source** を **「Deploy from a branch」** に設定
3. **Branch** で配信元ブランチ（PoC レビュー中は作業ブランチ、確定後は `main`）と
   フォルダ **`/docs`** を選び **Save**
4. 数十秒〜数分後、`https://<ユーザー名>.github.io/pal-partner-skills/` で公開されます

## データについて

- 出典は各種コミュニティ Wiki / データベースを突き合わせて整理します（`design/` 参照）。
- スキル効果値はパートナースキル**レベル（凝縮で 1→5 に上昇）**ごとに変わるため、レベル別に保持します。
- 重複（同名スキルの効果重ね掛け）の可否、拠点/手持ち/騎乗などの発動条件、
  αパル個体で効果が変わるケースなどをタグ・フラグで表現します。
