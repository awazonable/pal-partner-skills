# Palworld パートナースキル データベース

Palworld **v1.0** のパートナースキル一覧データベースと、特徴（タグ）ごとに絞り込めるフィルタ UI を、
**ビルド不要の静的アプリ**として提供します。GitHub Pages でそのままホストできます。

> ⚠️ 対象バージョンは **v1.0** です。β版から効果が変更されているスキルが多数あるため、
> β版時代の情報（stack 可・効果値など）とは区別して扱います。

## 構成

```
docs/                 # GitHub Pages の公開ルート（ビルド不要でそのまま配信）
├─ index.html         # UI 本体
├─ css/               # スタイル
├─ js/                # フィルタ/描画ロジック（バニラ JS, ES Modules）
└─ data/
   ├─ schema.md       # データスキーマ定義
   ├─ validate.py     # 参照整合性チェック
   ├─ tags.json       # タグ（特徴）マスタ（属性/作業/状態/発動場面/効果カテゴリ）
   └─ skills.json     # パートナースキル本体データ（288 件）
design/               # 設計ドキュメント（調査・スキーマ設計・UI 設計）＋ build.py（生成スクリプト）
```

収録件数は **288 件**（1 件＝1 パルのパートナースキル。B 亜種も別エントリ）。
効果値は **★0〜★4**（濃縮ランク＝5 段階レベル）で保持し、UI 右上の切替で全カードに反映されます。

## ローカルでの確認

ビルド不要です。`docs/` を静的サーバで配信するだけで動きます。

```bash
cd docs
python3 -m http.server 8000
# → http://localhost:8000
```

（`fetch` で JSON を読むため、`file://` 直開きではなく HTTP サーバ経由で開いてください。）

## GitHub Pages 公開手順（人間側の操作）

このリポジトリは「ブランチの `/docs` フォルダから配信」する方式です。

1. GitHub のリポジトリ **Settings → Pages** を開く
2. **Build and deployment → Source** を **「Deploy from a branch」** に設定
3. **Branch** で配信元ブランチ（PoC レビュー中は作業ブランチ、確定後は `main`）と
   フォルダ **`/docs`** を選び **Save**
4. 数十秒〜数分後、`https://<ユーザー名>.github.io/pal-partner-skills/` で公開されます

## データについて

- 出典は「パルワールド配合・攻略ラボ」のパートナースキル一覧（ユーザー提供の HTML）を
  `design/build.py` で構造化したものです（`design/01-research.md` 参照）。
- スキル効果値は **★0〜★4**（濃縮ランクで上昇）ごとに変わるため、★別の値を保持します。
  値はソース準拠の文字列（`+15%` / `250` / `特大` 等）。ソース側で ★0 省略の箇所は `—` 表示。
- **重複可否**（重複不可／可）、拠点/手持ち/騎乗/アクティブの**発動場面**、
  **属性・作業適性・状態異常**をタグ化してファセット絞り込みできます。
- **αパル個体で効果が変わるケース**は現ソースに明示が無いため未収録。スキーマは拡張可能な形に
  してあり、追記方法は `docs/data/schema.md` の注記を参照。

### データの再生成

```bash
python3 design/build.py <source.html> docs/data/tags.json docs/data/skills.json
python3 docs/data/validate.py   # 参照整合性チェック
```

（`<source.html>` は出典サイトのデータのためリポジトリには同梱していません。）
