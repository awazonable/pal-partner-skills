# UI / フィルタ設計

ビルド不要のバニラ（HTML/CSS/ES Modules）。`docs/` をそのまま GitHub Pages 配信。

│ フィルタ         │ 検索: [__________]   件数: 24 件   並替: [属性▾] │

## フィルタ仕様

- **ファセット検索**：`tags.json` のグループから自動でチェックボックス群を生成。
  - **グループ内 = OR**（例：属性で「火」「水」両方チェック → 火 or 水）。
  - **グループ間 = AND**（例：発動場面=手持ち かつ 詳細=釣り）。
- **テキスト検索**：スキル名 / Pal 名 / 説明文（ja・en）に部分一致（大文字小文字・かな無視は簡易）。
- **特殊トグル**（`effect`/`tags` とは別のスキル属性）：
  - 重複可のみ（`stackable === true`）
  - ユニークのみ（`unique === true`）
  - α差分ありのみ（`alpha.hasVariant === true`）
- **クリア**：全条件リセット。
- 各フィルタ項目に**該当件数**を併記（動的に更新、0 件はグレーアウト）。

## レベル表示

- ヘッダーの **Lv セレクタ（1〜5）** が全カードの数値効果に反映。
- 各効果値は `perLevel[selectedLv-1]`。`estimated:true` の値は `※` 付き（補間注記）。
- `flat` 効果は Lv 非依存である旨を淡色表示。

## カード表示

```
┌───────────────────────────────┐
│ [属性チップ] Pupperai            │  ← Pal 名 + 属性色チップ
│ Best Boy                        │  ← スキル名（大）
│ [手持ち][攻撃][近接]  [重複不可]  │  ← condition/effect/detail チップ + 重複バッジ
│ 近接武器ダメージ +22%           │  ← 効果（現在 Lv の値を強調）
│ 手持ちにいる間、近接武器…        │  ← 説明
│ (αでは効果変化 ⓘ)  ※未検証       │  ← α差分がある場合バッジ（クリックで展開）
└───────────────────────────────┘
```

- **属性チップ**は属性ごとの色。
- **α差分バッジ**：クリックで通常/α個体の効果を並べて表示。
- **未検証**（`verified:false`）はカードに控えめな「要検証」印。

## 並び替え

- Pal 名（あいうえお/ABC）、属性、発動場面、スキル名。既定：発動場面 → Pal 名。

## URL 状態同期（共有可能な絞り込み）

- 選択タグ・検索語・Lv を URL の hash（例：`#t=cond-party,detail-fishing&q=釣&lv=5`）に反映。
- 読み込み時に hash から復元。→ フィルタ結果をそのまま共有できる。

## アクセシビリティ / テーマ

- キーボード操作可（チェックボックス・ボタンにフォーカス可視）。
- ライト/ダーク両対応（`prefers-color-scheme` + 手動トグルは任意）。
- 相対単位・フレックス/グリッドでレスポンシブ。横スクロールはカード内で吸収。

## ファイル構成（実装）

```
docs/
├─ index.html            # 骨組み + マウントポイント
├─ css/style.css         # スタイル（テーマ変数含む）
└─ js/
   ├─ main.js            # 起動：データ取得→初期描画→イベント配線
   ├─ i18n.js            # {ja,en} から表示言語を選ぶ小関数
   ├─ filters.js         # tags.json からフィルタ UI 生成 / 絞り込みロジック
   └─ render.js          # カード描画 / 件数更新
```

依存ゼロ（フレームワーク不要）。`fetch` で JSON 読込のため HTTP 配信前提。
